# ICT 竞品分析 Skill：原始数据与口径说明

> 更新：2026-07-24
>
> 用途：作为 `reports/ict-competitive-analysis-efficiency-previous-push.html` 中时间、结果质量、痛点与目标数字的唯一人工核对底稿。展示页可以为了可读性四舍五入；本文件保留原始填写、标准化取值和计算规则。

## 1. 使用边界

- 样本为 8 位设计师在中大型功能场景下的自报数据，不代表所有任务的普遍时长。
- **竞品分析时间**与**设计时间**是两条并列的工作投入，不能互相扣除，也不能相加为一个总时长。
- “现有 Skill 分析时间”指从发起 Skill 分析到形成当前分析材料的时间，包含生成后的人工调整；不是单纯模型生成时长。
- “用不上，没变”保留为真实使用结果。为计算全样本的现有基线，报告用其传统分析时间作为现有时间的保守取值。
- 区间值只在报告统计时采用中点；原始区间仍完整保留在下表。

### 原始填写的说明

- 时昕昱的现有 Skill 分析时间曾记录为 10 天，后经确认用于当前报告的展示值为 **8 天**；本表按最终确认值保存。
- “分析时间 / 设计时间”中的设计时间，是该设计场景独立的设计投入，不是分析时间的总量或剩余量。
- 季舒婷、王心宇、徐文静的“现有分析时间 / 设计时间”并不等于上一列现有 Skill 完整分析时间；其原始表述反映的是设计投入与分析工作的并列关系，保留原文，不用于完整周期的均值计算。

这项比较只描述**竞品分析时间**。同期“现有 Skill 分析 5.1 天”和“设计时间 8.0 天”只作并列展示。

## 4. 指标定义

| 指标 | 分类 | 定义 | 分母 / 判定边界 |
| --- | --- | --- | --- |
| 完整分析周期 | 效率 | 从接到分析问题到形成可用分析材料的总时间。 | 包含范围确认、搜集、生成、核验、调整与成稿；不与独立设计时间相加。 |
| 首轮生成关键结论可采纳率 | 有效性 | 首轮生成后，经必要核验仍被保留，并进入设计判断或评审的关键结论比例。 | 分母为首轮生成的关键结论；“可采纳”不等于无需任何格式调整。 |
| 重大返工率 | 过程质量 | 因范围错误、关键证据缺失或核心判断不成立，而需要重定范围、重找证据或重做结构的任务比例。 | 一般润色或轻微排版调整不计入。 |

## 6. 维护规则

1. 新增或修改数据时，先更新本文件的“原始填写”，再更新“报告使用的标准化数据”。
2. 若展示页的数值变化，必须同步更新本文件的计算过程；若仅改变四舍五入，保留精确值不变。
3. 新补到逐字原声时，先追加到 `designer-interview-voices.md`，再在本文件更新来源说明。
4. 报告页面引用数值时，不得把并列的竞品分析时间与设计时间写成包含、剩余或相减关系。
