# DACM · CHI 参与者现场包

这是可直接用于招募和执行研究的一套材料，不向参与者暴露 DACM、研究假设、CANN/CUDA 对比结论或任何预期协同模式。

## 使用顺序

1. 向潜在参与者发送 `01-招募邀请.md`。
2. 研究开始时展示 `02-参与说明与同意.md`，收集同意。
3. 参与者填写 `03-背景问卷.md`。
4. 参与者按 `04-真实项目回放表.md` 准备并讲述一段真实 AI Coding 经历。
5. 参与者先完成情境 A，再完成 B；一半参与者按 A→B，另一半按 B→A。
6. 每个情境分别发放任务卡、材料包和作答模板。
7. 每个情境后填写 `09-情境后问卷.md`。
8. 最后使用 `10-结束说明.md` 收尾、确认脱敏与引用授权。

## 需在执行前补齐的材料

- `scenario-a/evidence/`：连续且可读的官方教程/样例页面快照或稳定链接；版本较清晰的环境清单。
- `scenario-b/evidence/`：动态 shape/Tiling/框架接入的跨页材料；版本并存、样例不完整或关键正文难取得的真实资料条件。
- 两个情境的 `starter/`：只用于阅读上下文的最小代码骨架，不要求参与者运行。
- 统一的、可检索的 AI 助手账号/界面；或明确参与者使用自己的账号，说明研究者不会读取其其他历史会话。

## 不向参与者提供

- “知识链连续/拼接”这类条件名称；
- 哪个生态或页面预期更好；
- 标准答案、建议路径、完整版本答案；
- 任何需要真实算卡才可确认的结论。
